# Datos

`b_depressed.csv` es el dataset de este avance. Hay un espejo en OpenML, id 43419.

La fuente pública no documenta el significado de las columnas ni cómo se construyó la etiqueta. En este repositorio el archivo se incluye para que el equipo pueda clonar y trabajar de inmediato.

`depressed` se trata como un indicador binario de la fuente: 0 = no deprimido y 1 = deprimido, según la descripción de OpenML. La construcción de ese indicador no está confirmada. No es un diagnóstico clínico.

`data/synthetic/` es un generador de juguete, sin personas reales.
